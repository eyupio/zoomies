## Findings considered and rejected

So nobody re-audits them:

- `__Host-` session cookie prefix (`internal/api/auth.go:365-375`): the
  attributes are otherwise right; exposure requires an attacker-influenced
  sibling subdomain on a shared parent domain, atypical for self-hosted
  dedicated hosts, and the fix carries real rollout cost (the CLI's
  `SessionCookie` constant, live sessions). Revisit only if the product
  moves to shared-domain deployments.
- Rate-limiter reset on `agent.heartbeat_interval` change
  (`internal/controller/agent_limits.go:56-63`): a one-off budget refresh
  triggered by an operator's own settings edit; single-burst impact.
- "God files" (`daemon.go`, `problems.go`, `installer.go`, `models.go`):
  likely deliberate one-file-tells-the-story style; only worth acting on
  alongside 009 if merge friction actually bites.
- Audit-row retention, embedded-migration squashing, views aliasing
  (already clean), `make dev` auth-off mode: all by-design, verified.
- The `os.SameFile` re-check branch in `boundLog` is left untested
  deliberately (no seam without hooks); recorded in 003's Maintenance notes.
